# Generative AI at UW – Best Practices

Website developed for the report  
**“Generative AI at UW – Best Practices”**  
(DELab UW, University of Warsaw).

The website presents an interactive, continuously updated web version of the report on the use of generative AI in research, teaching, and administrative processes at the University of Warsaw.
Link: https://delab-uw.github.io/genai_site/

## My role
I was responsible for:
- full website development and structure,
- implementation using MkDocs,
- visual design and layout customization,
- content integration and formatting for web presentation,
- deployment and maintenance of the interactive website.

The analytical and policy content of the report was developed by the DELab UW research team.  
My contribution focused on **web implementation, user experience, and visual presentation of the report**.

## Tech stack
- **Python** (MkDocs)
- **Markdown**
- **HTML / CSS / JavaScript**
- MkDocs theme customization
- GitHub Pages (deployment)

## Project scope
- interactive web-based version of a policy and best-practices report,
- structured navigation of report chapters and guidelines,
- presentation of survey-based results and recommendations,
- bilingual content support (English / Polish),
- responsive design for desktop and mobile devices,
- access to downloadable PDF version of the report.
